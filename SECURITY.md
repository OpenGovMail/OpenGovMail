# Security Policy

## Supported Versions

Security fixes go into the latest release.

| Version | Supported |
| ------- | --------- |
| 0.6.x   | ✅ |
| < 0.6   | ❌ |

Raven has its own [security policy](https://github.com/OpenGovMail/raven/blob/main/docs/SECURITY.md) and supported versions.

## Reporting a Vulnerability

Please don't open a public issue for a security problem. Report it by emailing **security@opensource.lk** with:
- A detailed description of the issue
- Steps to reproduce the vulnerability
- Impact and possible mitigations

We will respond within 48 hours to acknowledge receipt of your report. Once confirmed, we will work on a fix and notify you when the vulnerability is resolved.

For urgent security issues, please use **PGP-encrypted email** with our [PGP public key](https://github.com/OpenGovMail/raven/blob/main/docs/keys/PGP_PUBLIC_KEY.asc).

## Reporting Illegal Content

OpenGovMail is software that organizations install on their own servers. The organization running a deployment controls its accounts and data and is responsible for the content on it. The OpenGovMail maintainers have no accounts on deployments and can't read their data.

- To report illegal content on a deployment, including child sexual abuse material, contact the organization that runs it and your national law enforcement authorities.
- To report illegal content in this project's repositories, issues or discussions, email the address above. We will remove it and report it to the authorities where the law requires.
