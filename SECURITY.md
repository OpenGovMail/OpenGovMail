# Security Policy

If you find something wrong in OpenGovMail, please tell us. That can be a security vulnerability, an unsafe default, a way the software puts people's mail or personal data at risk, or anything else we do that could cause harm. We read every report and will try to fix the problem.

## Supported Versions

Security fixes go into the latest release.

| Version | Supported |
| ------- | --------- |
| 0.6.x   | ✅ |
| < 0.6   | ❌ |

Raven has its own [security policy](https://github.com/OpenGovMail/raven/blob/main/docs/SECURITY.md) and supported versions.

## Reporting a Problem

Please don't open a public issue for a security problem. Email **security@opensource.lk** with:
- A description of what you found
- Steps to reproduce it
- The impact, and any fix you can suggest

We will reply within 48 hours to confirm that we have your report. Once we confirm the problem, we will work on a fix and tell you when it is released.

For urgent security issues, please use **PGP-encrypted email** with our [PGP public key](https://github.com/OpenGovMail/raven/blob/main/docs/keys/PGP_PUBLIC_KEY.asc).

Problems that are safe to discuss in public, such as a confusing setting or a gap in the docs, can go in a [GitHub issue](https://github.com/OpenGovMail/OpenGovMail/issues).

## Self-Hosted Deployments

OpenGovMail is software that organizations install on their own servers. The organization running a deployment controls its accounts and data and is responsible for the content on it. The OpenGovMail maintainers have no accounts on deployments and can't read their data.

- To report a problem with how one deployment is set up or run, contact the organization that runs it. If the cause is in OpenGovMail itself, also tell us.
- To report illegal content on a deployment, including child sexual abuse material, contact the organization that runs it and your national law enforcement authorities.
- To report illegal content in this project's repositories, issues or discussions, email the address above. We will remove it and report it to the authorities where the law requires.
